# Enigma Machine — 3D CAD Assembly (Autodesk Inventor)

Reverse-engineered 3D model of an Enigma machine, built for the Engineering
Graphics course at IIT Gandhinagar. Components were measured from a physical
reference, modeled to spec in Autodesk Inventor, assembled with motion
constraints, and animated to demonstrate the rotor-stepping mechanism.

## Files
- `EnigmaMachine.step` — full assembly, opens in any CAD software
- `/images` — assembled and exploded views

Built with Autodesk Inventor Professional 2025.
